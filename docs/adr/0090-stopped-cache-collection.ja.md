# ADR 0090: 停止した通常Envから完成した世代を収集する

状態: 採用、実装候補。[English](0090-stopped-cache-collection.md)

## 決定

設定したキャッシュ領域はEnv所有の使い捨てデータです。内容は通常Envの作業で生成し、作成前のHost設定が対象パスと互換条件を選びます。Host管理処理はこのデータを実行してキャッシュを作りません。

既存のEnvとWorkspaceのロックを保持して収集します。snapshotと共有するlease・実体IDの検証を行い、停止を確認し、現在のleaseから対象領域を解決します。providerへ依頼する前に、正確な子領域と新規の共通元候補を同じ取引で予約します。通常コピーは接続済み領域を拒否したままです。収集の例外は、稼働可能な正確な親・登録済み子領域・生成元とコピー元世代を保持した世代候補に限ります。

providerも唯一の通常Env接続先、生成時の実体ID、明示的データdevice、停止状態、自動起動の無効化を照合します。Host停止・再開やguestの確認用プログラムは使いません。CopySourceの永続予約で、プロセス終了後も親の再開・クライアント接続・削除を止めます。コピー完了を正確に記録してから、共通の世代採用処理へ進みます。古い生成元は新しい世代を置き換えられず、結果不明のコピー・採用は所有権を保持します。来歴は完成後も残しますが、生成元や古いWorkspace leaseを保持し続ける理由にはしません。

設定と収集は既存の信頼済みcontroller通信だけへ公開します。設定はリビジョン照合、非公開ファイルの排他、一括置換と同期で保存します。新規Envは読み直し、既存の配置は変更しません。操作表示には設定名・パス・世代番号・次の手順を使います。

## 不採用案と残件

接続済み領域のコピーを一律に許すと、OCIの書き込み排他や親の所有管理を迂回できます。leaseを一時的に外す、任意のdeviceを切り離す、source guardを無効にする、guestへ管理権限を渡す方式は既存の境界を弱めます。ファイル単位のマージでは未完成・非互換のデータを採用する可能性があります。

コピー先が存在するだけでは中断した処理の完了を証明できません。利用者自身で完結する復旧、履歴・クリア、既存Envへの登録、追加領域を含むsnapshot・転送は未完成です。旧版互換の仕組みは追加しません。実機での機能確認と巨大レポ測定は別の証拠です。

復旧も同じ所有権原則に従う。共通コピー復旧はOCIの呼び出し元も含め正確な参照を必須とする。Standardが名前付き候補を特定し、共通serviceが永続完了記録とproviderを確認して一度だけ完了する。世代比較は共通処理を使うが、古い完成候補が過去に未選択だったとは断定できないため保持する。コピー再実行や存在だけの完了推定は行わない。
