# ADR 0112: 操作記録に基づく中断したキャッシュ収集の後片付け

状態: 採用。[English](0112-interrupted-cache-copy-cleanup.md)

## 決定

予約済みの収集候補にIncus非同期操作を保存してから完了を待ちます。失敗時は完了保存を原子的に禁止し、保存した操作の終了を確認して、共通の所有者確認付き削除へ移ります。コピー先の不存在確認とカタログの削除確定までCopySourceを保持します。保存済みの削除中状態は、終了確認を通過した証拠です。プロセス終了後は既存のcache recoverで再開します。

Incusのvolumeコピーは取消に対応しない場合があります。クライアントのタイムアウト、volume・操作の欠落、不正な応答、実体の存在を停止・完了の証拠にしません。操作記録が未取得・期限切れなら復旧待ちです。実コピーが完了しても完了記録がなければ失敗時のコピー先として破棄し、存在だけで採用しません。完了記録付きコピーと世代採用結果不明の従来復旧は維持します。

対象は停止した通常Envからのキャッシュ収集です。一般コピー・OCI・作成時のキャッシュ配置・ライフサイクル権限は変更しません。guestへの管理資格情報、Hostパス推測、ファイル単位マージを追加しません。

## 却下した方法

CLI失敗直後の削除は動作中のdaemonコピーと競合します。不存在確認前の元予約解放は並行書き込み・削除を許します。共通削除を迂回した独自削除は所有権・世代保護を欠きます。終了証拠がある追跡済みコピーまで永久保持すると、通常Envの再利用を不要に妨げます。
