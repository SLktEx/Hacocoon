# ADR 0099: Baseアーカイブを一時作成環境のライフサイクルで取り込む

状態: accepted
日付: 2026-09-15

## 決定

サイズ制限付きの非圧縮コンテナイメージを、Env転送と共通の、controller所有の
名前のない一時ファイルに固定する。Incusだけが形式と内容を解釈し、イメージの
設定を新しい一時所有情報に置き換える。既存の正規アーカイブ作成処理で独立した
一時Envを作り、設定より前に正確な所有情報を記録する。定義/Packerと同じEnv内の
一時Workspace、有限の資源上限、現行ネットワーク保護、認証境界を使う。
整理・停止・不変イメージの公開・Base参照の更新も既存の作成処理に集約する。

## 採用しない方法

転送用一時イメージをそのままBaseにすると、所有と削除の契約に反する。
Hostでの展開やスクリプト実行は、入力にHostの権限を与えてしまう。
特別な権限、ネットワーク緩和、Hostのマウント、認証情報の再利用は通常Envの
隔離を迂回する。別の作成・cleanup台帳は正規ライフサイクルと公開記録を重複させる。
アーカイブからdevice・profile・Policy・認証情報・controller側パスを指定できない。

## 結果

入力は保持し、毎回独立した所有情報で取り込む。作成や公開の結果が不明なら記録を
残し、自動再試行しない。既存Envの不変revisionはBase参照の更新に追従しない。
入力のtemplateは再実行しない。初期対応は非圧縮の単一Incusコンテナイメージで、
Env bundle、VM、圧縮、任意の外部取得は対象外。非公開の一時保存と通常Env転送の
既存テストと動作を維持する。
