# ADR 0080: 互換用の処理を残さずSeedの実装を撤去する

状態: accepted、実装候補。[English](0080-seed-runtime-retirement.md)

日付: 2026-09-15

## 判断

Envの作成は明示的なBaseとrevisionを解決します。Seedの構成、resolverのオプション、
builderと公開、harvest、保守、CLIを撤去します。OCIプラグインの切替でBaseを黙って
差し替えたり、入れ子コンテナの権限を増やしたりしません。現在のBase・永続OCIの契約を維持します。

まだテスト中の製品であるため、ユーザーは旧バージョンの互換性・移行を明示的に対象外と
しました。収集・推奨と、観測・削除の旧カタログを、移行用のイメージ削除・再有効化と
ともに完全に撤去します。読み取り・変換・無効化したresolverを将来の呼出し用に残しません。
現在の管理対象イメージの経路を正規の削除手順とします。任意のDocker連携は、撤去する
Seed状態やHostの実行器に依存させません。

撤去した製品経路だけを試すテストと非公開レジストリの手動jobを削除します。過去の
証拠は現在の確認と区別して保持します。現行版の通常テストは実際の製品経路を確認し続けます。

## 採用しない方法

無効化したresolverや旧観測の読み取りを残すと、現在の要件がない複雑さと別の状態経路が
残ります。プラグインの切替はBase差替えの許可ではありません。`switch-base`は復活させません。

コードの撤去をデータ削除操作にはしません。ユーザーのファイル、Workspace、OCI Store、
nativeリソースを自動削除せず、不明確な所有権を解放せず、現在の寿命・権限確認を緩めません。

[Seed撤去](../design/oci-seed-and-cow.ja.md)と
[データの寿命](../guides/data-lifetime.ja.md)を参照してください。
