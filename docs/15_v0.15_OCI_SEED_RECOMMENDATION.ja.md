# v0.15 — OCI Seed Usage & Recommendation

[English](15_v0.15_OCI_SEED_RECOMMENDATION.md) | **日本語**

Status: **optional OCI pluginのfirst sliceを実装済み。**

operatorがOCI pluginを明示enableした場合だけworkload OCI image identityを観測する。

```text
HACO_PLUGIN_OCI=nerdctl  # または docker
haco plugin oci seed sample
haco plugin oci seed recommend
```

trusted HostにはEnvironmentごとのlatest snapshotとしてsample時刻、repository、tag、取得できる場合はimmutable digestだけを保存する。shell history、container output、registry secret、Workspace contentは記録しない。

recommendationはsample回数ではなくrecentなdistinct Environment数で重み付けする。mutable tagしかないimageはSeed identityとして推薦しない。現在のselection policyはeligible recommendationの上位10%をfuture Seed Builderの自動採用候補としてmarkするが、現時点でBase/Seed自体をmutationしない。

OCI toolingはoptional。`HACO_PLUGIN_OCI`未設定ならserviceをcomposeせず、Coreはnerdctl/Dockerを要求しない。
