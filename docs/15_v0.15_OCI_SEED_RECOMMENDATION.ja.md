# v0.15 — OCI Seed Recommendation

Status: **`main` に実装済み。physical Seed build/publishはv0.19。**

v0.15は将来のOCI Seed選択をusageベースにします。provider-neutralなEnvironment execution pathからimage usageを観測し、trusted Host側にsnapshotを保存し、immutable image identityをrecommendし、上位10%を次回Seedへのautomatic promotion対象にします。

## CLI

```text
haco image seed sample
haco image seed recommend
```

## Telemetry model

HostはEnvironmentごとのlatest OCI image snapshotを保持します。記録するのはSeed selectionに必要なidentityのみです。

- Environment identifier
- sample timestamp
- repository/reference
- tag（存在する場合）
- immutable digest（観測可能な場合）

command history、container output、registry credential、credential-helper response、Workspace contentsは記録しません。

現在のdefault:

- 6時間以内のsnapshotはopportunistic samplingではfresh扱い
- recommendation windowは直近30日
- Environmentごとにlatest snapshotだけをcountするため、同じEnvironmentを何度sampleしてもweightは増えない

## Immutable identity

Recommendationにはimmutable digestが必要です。mutable tagだけではSeed identityとして扱いません。

```text
reference@sha256:...
```

Tagが別digestへ移動した場合は別recommendation identityです。

## Automatic promotion

eligible recommendationをdeterministicにrankし、上位10%を `auto_promote=true` にします。

```text
1-10 candidates   -> 1 auto
11-20             -> 2 auto
21-30             -> 3 auto
```

countは `ceil(eligible_count * 0.10)`、candidateが1件以上なら最低1件です。

human-readable outputでは`auto`、JSONでは`auto_promote`を公開します。

## Safety boundary

Automatic promotionが選ぶのはOCI image contentであり、credentialや任意のEnvironment dataではありません。

- registry/Host credentialをSeedへpromotionしない
- Workspace fileをtelemetryへ入れない
- sample失敗をempty Environmentとして黙殺しない
- immutable digestがないimageはauto selectionしない
- existing Environment / published immutable Seedを直接mutationしない
- v0.16 deletion tombstoneは同一identityのrecommendation/auto promotionより優先

## v0.19との関係

v0.15は**将来のSeedに何を入れるか**を決めます。Host-side acquisition、offline Seed Builder、immutable publication、current-Seed pointer、Btrfs/COW integrationはv0.19の責務です。
