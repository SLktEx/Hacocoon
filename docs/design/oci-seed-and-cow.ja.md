# OCI Seedの撤去

日本語 | [English](oci-seed-and-cow.md)

状態: **実装済みの撤去候補**。2026-09-15のユーザーによる範囲変更に従い、
旧バージョンとの互換性・移行は今回のM0〜M5の対象外です。旧カタログの読み取りや
変換専用の処理は残しません。

新規Envは明示的に選んだBaseと固定revisionを使います。OCIプラグインの設定だけで
Seedへ差し替えたり、入れ子コンテナの権限を変更したりしません。Seedの構成・選択・
コマンド・harvest・構築と公開・保守・カタログ・収集・推奨・削除記録・再有効化を
撤去しました。現在のBase構築、独立したWorkspace、snapshot、export/import、
管理対象のイメージ削除、永続OCI Storeの契約は維持します。
[ADR 0080](../adr/0080-seed-runtime-retirement.ja.md)を参照してください。

## 現在の境界

コードの撤去に伴うリソース削除は行いません。setupと通常Envの作成は`seeds.json`や
`oci-usage.json`を読み取らず、移行もしません。旧イメージ、名前空間、ファイル、
インストール環境を自動清掃しません。現在の所有権とデータ保持の判断は正規の
ライフサイクル処理を使います。共用の管理対象種別マーカーはEnv識別処理へ移し、
値を保持します。そのマーカーを所有者確認の代わりにはしません。

現在の`haco plugin oci image ...`は対象runtimeの状態を確認し、レビューした範囲を
削除します。撤去したSeedのイメージ削除処理は共用しません。任意のDocker連携は独立して
維持します。`switch-base`は復活させません。現在の操作は
[データの寿命](../guides/data-lifetime.ja.md)と[イメージ削除](oci-image-deletion.ja.md)を
参照してください。

## 証拠と引き続き守る制約

以前の実装と[過去の証拠](../status/seed-private-registry-acceptance.ja.md)はGit履歴と
証拠の記録に残ります。Seed専用の非公開レジストリ試験と手動jobは、その製品経路と
ともに撤去しました。現行Storeの認証確認へ読み替えず、旧バージョンの移行を完了条件にしません。

独立したEnvで書込み可能な`/var/lib/containerd`を共有せず、再利用可能なHost認証情報を
イメージへ入れず、CoreからIncus所有のBtrfs領域を直接操作しません。不明確な後始末で
所有権を解放しません。現行のBase・OCI Storeはそれぞれの寿命・権限・CoW契約を守ります。
性能測定と追加の受け入れ確認は、利用できる実装を揃えてから進めます。
