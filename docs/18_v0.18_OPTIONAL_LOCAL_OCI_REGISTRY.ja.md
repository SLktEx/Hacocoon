# v0.18 — Optional Local OCI Registry

[English](18_v0.18_OPTIONAL_LOCAL_OCI_REGISTRY.md) | **日本語**

Status: **planned。Hacocoon必須インフラとしては未実装。**

operatorがregistry/proxy integrationを明示enableしない限り、Environmentの通常pullは許可されたupstream OCI registryへ直接行う。

```text
Default:
Environment -> allowed upstream registry

Optional:
Environment -> operator-selected local registry/proxy -> upstream
```

Local Registryは同一imageの再download、rate limit、Internet制限環境、centralized OCI policy/audit pointが必要な場合には有用だが、OCI Seed constructionには必須ではなくCore dependencyにしない。

認証は別のauthority問題。Host registry credentialをcoding Environmentへ暗黙copyしない。future scoped credential-broker pluginはimage data pathをlocal proxyへ強制せずに利用できる。

operatorがmediation必須と設定した場合、registry failureからunrestricted direct Internetへsilent fallbackしてはいけない。
