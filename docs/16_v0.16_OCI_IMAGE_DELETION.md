# v0.16 — OCI Image Deletion

Status: **first slice implemented in the optional OCI plugin.**

```text
haco plugin oci image delete <reference[@sha256:...]> [--all-environments] [--json]
```

Deletion is an operator decision about optional Seed selection, not a global runtime/network denylist.

## Safety rules

- Resolve deletion to immutable `reference + digest` identity.
- Ambiguous mutable tags fail closed and require an explicit digest.
- Re-check a mutable reference before removal so a moved tag is not deleted as the old image.
- Record a trusted deletion tombstone so ordinary sampling cannot immediately auto-promote the same identity again.
- Do not modify existing Environments unless `--all-environments` is explicit.
- Never use force image removal.
- Docker driver selection does not imply authority over an arbitrary Host Docker daemon.
- Published immutable Seeds are never edited in place; deletion requires a future replacement Seed build.

The project-maintained nerdctl profile may operate a dedicated Host Seed-cache namespace. That Host cache is plugin-owned optional state, not a Core requirement.
