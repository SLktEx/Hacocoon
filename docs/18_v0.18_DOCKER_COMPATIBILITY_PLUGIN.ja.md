# v0.18 — Docker Compatibility Plugin

[English](18_v0.18_DOCKER_COMPATIBILITY_PLUGIN.md) | **日本語**

Status: **foundationは先行実装済み。complete plugin integrationはv0.17 Seed/Base pipelineの後にfollow-up。**

v0.18はDocker互換をoptional plugin/integrationとして扱います。Hacocoon CoreはEnvironmentとExecutionを扱い、Docker Engine / containerd / nerdctlを必須にしません。

## Maintained OCI profile

project-maintained OCI plugin profileでは `containerd + nerdctl` を使えます。これはCore invariantではありません。

Docker互換は追加機能です。

```text
maintained profile -> nerdctl -> containerd
compatibility      -> genuine Docker CLI -> optional/on-demand dockerd -> existing containerd where supported
```

## Ordering dependency

このfeatureを完成させるには、Incus Environment内へ選択したOCI workload profileを確実に配置・維持できるEnvironment/Base provisioning pathが必要です。そのphysical Seed/Base pathはv0.17が担当します。

repositoryにはDocker driver supportとplugin-owned systemd socket/service packagingが既にありますが、これらはv0.18の先行foundation実装として扱います。v0.17より先にv0.18 completeを意味しません。

## Plugin boundary

- Docker/nerdctl固有処理は `modules/plugin/oci` / `haco plugin oci` に置く。
- `HACO_PLUGIN_OCI=nerdctl|docker` で明示opt-in。未設定ならOCI pluginなし。
- genuine Docker CLIは選択profileで提供可能。
- dockerdをalways-on要件にしない。
- EngineはEnvironment-localかつ必要時on-demand。
- Host Docker socketをmountしない。
- CoreへDocker固有概念を持ち込まない。

## 現在のrepository reality

Docker compatibility design、Docker-backed OCI adapter behavior、plugin-owned systemd socket/service packaging foundationは存在します。ただし **v0.18はまだcompleteではありません**。v0.17 Seed/Base provisioning、full Docker lifecycle integration、supported-host acceptanceが必要です。
