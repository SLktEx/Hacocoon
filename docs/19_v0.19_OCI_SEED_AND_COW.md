# v0.19 — OCI Seed Builder & Btrfs/COW

Status: **planned. Usage/recommendation and deletion policy exist in v0.15/v0.16; physical Seed build/publish is not implemented yet.**

The planned optimization flow is:

```text
trusted Host
  -> acquire approved OCI content and immutable digest
  -> OCI export / stream
  -> offline Seed Builder (no arbitrary upstream network)
  -> containerd import/unpack
  -> clean containerd stop
  -> immutable Incus Seed publish
  -> normal Incus clone
  -> Btrfs/COW sharing when supported by storage backend
```

## Non-negotiable separation

Never share one writable `/var/lib/containerd` between Environments. Each Environment has independent logical containerd state. Physical sharing is left to immutable image/clone semantics in Incus and the storage driver.

Seed identity is based on the pinned parent Base revision and immutable OCI digests. Mutable tags are convenience inputs only.

The Seed Builder receives content from the trusted Host and should be offline, preferably without a NIC. Registry credentials remain Host-owned and are never baked into the Seed.

A Local Registry is not required for this design.
