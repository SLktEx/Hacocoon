# v0.13B — OCI Plugin Seed 自動昇格ポリシー

Status: **候補選定ポリシーはoptional OCI plugin内で実装済み。Seed buildへの自動反映はbuild実装時に接続する。**

この文書は `13A_v0.13_OCI_SEED_AND_COW.ja.md` の recommendation 方針を更新する。ここで扱うtelemetry / recommendation / promotionはすべてoptionalな `modules/plugin/oci` の責務であり、Hacocoon Coreの必須機能ではない。

## Default policy

OCI pluginが有効な場合、直近の利用統計からSeed recommendationをランキングし、immutable OCI digestを持つeligible candidateの **上位10%** を次回Seedへ自動昇格する。

件数は切り上げ、候補が1件以上ある場合は最低1件を自動昇格する。

```text
eligible candidate数   自動昇格数
1-10                    1
11-20                   2
21-30                   3
...
```

式では以下。

```text
auto_count = ceil(eligible_count * 0.10)
```

ただし `eligible_count > 0` のとき `auto_count >= 1` とする。

ランキング順はdeterministicにする。

1. exact image identityを含むrecent Environment数の降順
2. 最終観測時刻の降順
3. image referenceの昇順
4. digestの昇順

plugin利用統計のdefaultは直近30日、opportunistic samplingは6時間以内のsnapshotをfreshとする。

## Immutable identity 必須

自動昇格対象はimmutable digestを観測できたrecommendationだけとする。digestの無いmutable tagは自動昇格しない。

選択されるidentityは概念上以下になる。

```text
reference@sha256:...
```

tagが別digestに動いた場合は別recommendation identityとして扱う。

## CLI / machine-readable contract

`haco plugin oci seed recommend` のhuman-readable outputでは、自動昇格対象を `auto` と表示する。

OCI pluginは明示的に有効化する。

```text
HACO_PLUGIN_OCI=nerdctl haco plugin oci seed recommend
HACO_PLUGIN_OCI=docker  haco plugin oci seed recommend
```

JSON recommendationは以下のfieldを持つ。

```json
{
  "reference": "docker.io/library/node:24",
  "digest": "sha256:...",
  "environments": 18,
  "percent": 90.0,
  "auto_promote": true
}
```

今後のOCI plugin Seed Builderは `auto_promote=true` のimageを次回Seed inputに自動追加する。imageごとの手動承認は要求しない。

ただし、既にpublish済みのSeedやexisting Environmentをその場で書き換えることはしない。自動昇格が反映されるのは **次に作るimmutable Seed revision** である。

OCI pluginが無効ならCoreはこのtelemetryを収集せず、OCI Seedの自動昇格も行わない。

## Safety boundary

自動昇格するのは **OCI image contentのidentity** だけであり、credentialやauthorityではない。

以下はSeedに自動昇格しない。

- registry password / token
- credential-helper response
- workspace data
- arbitrary Environment files

経路はoptional plugin内で以下のまま維持する。

```text
optional OCI plugin usage telemetry
      |
      v
rank + 上位10% auto selection
      |
      v
trusted Host seed cache/acquisition
      |
      v
Offline Seed Builder
      |
      v
immutable Seed revision
```

自動選択されたimageが含まれていても、partial/failed Seed buildをcurrent Seedに昇格してはいけない。
