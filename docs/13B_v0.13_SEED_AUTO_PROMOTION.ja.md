# v0.13B — Seed 自動昇格ポリシー

Status: **候補選定ポリシーは実装済み。Seed build への自動反映は build 実装時に接続する。**

この文書は `13A_v0.13_OCI_SEED_AND_COW.ja.md` の recommendation 方針を更新する。13A にある「Seed への昇格はすべて operator 承認」という部分については、このポリシーを優先する。

OCI / containerd / nerdctl 固有の操作は Hacocoon Base image の CLI と分離し、optional な OCI plugin namespace 配下に置く。

## Default policy

Hacocoon は直近の利用統計から Seed recommendation をランキングし、immutable OCI digest を持つ eligible candidate の **上位10%** を次回 Seed へ自動昇格する。

件数は切り上げ、候補が1件以上ある場合は最低1件を自動昇格する。

```text
eligible candidate数   自動昇格数
1-10                    1
11-20                   2
21-30                   3
...
```

式では以下。

```text
auto_count = ceil(eligible_count * 0.10)
```

ただし `eligible_count > 0` のとき `auto_count >= 1` とする。

ランキング順は deterministic にする。

1. exact image identity を含む recent Environment 数の降順
2. 最終観測時刻の降順
3. image reference の昇順
4. digest の昇順

利用統計の default は引き続き直近30日、opportunistic sampling は6時間以内の snapshot を fresh とする。

## Immutable identity 必須

自動昇格対象は immutable digest を観測できた recommendation だけとする。digest の無い mutable tag は自動昇格しない。

選択される identity は概念上以下になる。

```text
reference@sha256:...
```

tag が別 digest に動いた場合は別 recommendation identity として扱う。

## CLI / machine-readable contract

`haco plugin oci seed recommend` の human-readable output では、自動昇格対象を `auto` と表示する。

JSON recommendation は以下の field を持つ。

```json
{
  "reference": "docker.io/library/node:24",
  "digest": "sha256:...",
  "environments": 18,
  "percent": 90.0,
  "auto_promote": true
}
```

今後の Seed Builder は `auto_promote=true` の image を次回 Seed input に自動追加する。image ごとの手動承認は要求しない。

ただし、既に publish 済みの Seed や existing Environment をその場で書き換えることはしない。自動昇格が反映されるのは **次に作る immutable Seed revision** である。

## Safety boundary

自動昇格するのは **OCI image content の identity** だけであり、credential や authority ではない。

以下は Seed に自動昇格しない。

- registry password / token
- credential-helper response
- workspace data
- arbitrary Environment files

経路は以下のまま維持する。

```text
usage telemetry
      |
      v
rank + 上位10% auto selection
      |
      v
trusted Host seed cache/acquisition
      |
      v
Offline Seed Builder
      |
      v
immutable Seed revision
```

自動選択された image が含まれていても、partial/failed Seed build を current Seed に昇格してはいけない。
