# v0.13 — Managed Sandbox Network

Status: **implemented first slice on `main`; real supported-Incus network acceptance remains host-dependent.**

v0.13 makes the local Incus transport boundary an explicit Hacocoon-managed resource instead of silently trusting a broad/default profile.

## Contract

- Hacocoon creates/uses its managed sandbox network/profile for local Incus Environments.
- Drift or an unsafe broad fallback fails closed instead of silently weakening isolation.
- IP/CIDR transport enforcement and hostname/domain-aware authorization are separate layers.
- Provider-specific Incus mechanics stay outside Core domain vocabulary.

```text
Environment
    |
managed Hacocoon Incus profile/network
    |
default-deny transport boundary
    |
higher-level policy / broker
```

Domain-aware egress policy can be layered above this transport boundary; it is not implemented by pretending DNS names are stable IP allowlists.

## Acceptance

Repository tests cover managed-resource creation, drift and fail-closed behavior. Real Incus/WSL networking remains a separate host-dependent acceptance gate.
