# v0.19 — OCI Seed Builder & Btrfs/COW

[English](19_v0.19_OCI_SEED_AND_COW.md) | **日本語**

Status: **planned。v0.15/v0.16のusage/recommendation/deletion policyは実装済みだが、physical Seed build/publishは未実装。**

planned flow:

```text
trusted Host
  -> approved OCI content取得 + immutable digest確定
  -> OCI export / stream
  -> offline Seed Builder（arbitrary upstream networkなし）
  -> containerd import/unpack
  -> containerd clean stop
  -> immutable Incus Seed publish
  -> normal Incus clone
  -> storage backendが対応する場合Btrfs/COW sharing
```

## 絶対に守る分離

複数Environmentで1つのwritable `/var/lib/containerd`を共有しない。各Environmentは独立したlogical containerd stateを持つ。physical sharingはIncusのimmutable image/clone semanticsとstorage driverへ任せる。

Seed identityはpinned parent Base revisionとimmutable OCI digestに基づく。mutable tagはinput convenienceにすぎない。

Seed Builderへはtrusted Hostからcontentを渡し、builderはoffline、できればNICなしとする。registry credentialはHost-ownedのままSeedへ焼き込まない。

Local Registryはこの設計に必須ではない。
