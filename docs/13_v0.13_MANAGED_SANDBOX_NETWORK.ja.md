# v0.13 — Managed Sandbox Network

[English](13_v0.13_MANAGED_SANDBOX_NETWORK.md) | **日本語**

Status: **`main` にfirst slice実装済み。real supported-Incus network acceptanceはhost-dependent。**

v0.13ではlocal Incusのtransport boundaryをHacocoon-managed resourceとして明示し、broad/default profileへ暗黙fallbackしない。

## Contract

- local Incus EnvironmentはHacocoon-managed sandbox network/profileを使う
- driftやunsafeなbroad fallbackはfail closed
- IP/CIDR transport enforcementとhostname/domain-aware authorizationは別layer
- Incus固有mechanicsはCore domain vocabularyへ持ち込まない

```text
Environment
    |
Hacocoon-managed Incus profile/network
    |
default-deny transport boundary
    |
higher-level policy / broker
```

Domain-aware egressは上位policy/brokerで扱う。DNS名を固定IP allowlistのように扱って代用しない。

## Acceptance

repository testでmanaged resource creation / drift / fail-closedを検証する。real Incus/WSL networkingは別のhost-dependent acceptance gate。
