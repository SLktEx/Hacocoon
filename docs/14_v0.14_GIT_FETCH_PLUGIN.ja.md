# v0.14 — Git Fetch Plugin

[English](14_v0.14_GIT_FETCH_PLUGIN.md) | **日本語**

Status: **`main` に実装済み。**

v0.14は既存Git/GitHub extension surfaceへpolicy-scoped fetchを追加する。ordinary GitをHacocoon Coreの責任にはしない。

```text
haco plugin git fetch <environment>
haco plugin git fetch <environment> --remote upstream
```

## Authority boundary

- registered Workspaceのrepository identityとGitHub remoteをprivileged execution前に検証する
- repository-controlledな`remote.<name>.fetch`ではなく、検証済みGitHub URLと固定remote-tracking refspecを使う
- tag / submoduleを暗黙取得しない
- GitHub HTTPS認証はHost所有の`gh auth git-credential`を明示利用する
- credentialをEnvironment、repository、capability request、audit logへコピーしない
- SSH remoteは既存のhardened broker経路でHost key/agentを利用できる

fetch/pushは`haco plugin git`配下。`git status` / `diff` / `commit` / worktreeなどordinary Git UXはGit自身の責任。

security contractは [`GIT_GITHUB_CAPABILITY.md`](GIT_GITHUB_CAPABILITY.md) を参照。
