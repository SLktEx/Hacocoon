# v0.16 — OCI Image Deletion

[English](16_v0.16_OCI_IMAGE_DELETION.md) | **日本語**

Status: **optional OCI pluginのfirst sliceを実装済み。**

```text
haco plugin oci image delete <reference[@sha256:...]> [--all-environments] [--json]
```

image deletionはoptional Seed selectionに対するoperator decisionであり、global runtime/network denylistではない。

## Safety rule

- deletionをimmutableな`reference + digest`へresolveする
- ambiguousなmutable tagはfail closedしexplicit digestを要求する
- remove直前にmutable referenceを再確認し、tag move後のnew imageをold imageとして削除しない
- trusted deletion tombstoneを保存し、ordinary samplingが同じidentityを即auto-promoteしないようにする
- `--all-environments`がない限りexisting Environmentを書き換えない
- force image removalを使わない
- Docker driverを選んでもarbitrary Host Docker daemon authorityを得たとは扱わない
- published immutable Seedをin-place編集しない。削除反映はfuture replacement Seed buildで行う

project-maintained nerdctl profileはdedicated Host Seed-cache namespaceを使えるが、これはplugin-owned optional stateでありCore requirementではない。
