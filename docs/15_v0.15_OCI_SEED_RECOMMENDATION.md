# v0.15 — OCI Seed Usage & Recommendation

Status: **first slice implemented in the optional OCI plugin.**

This milestone observes workload OCI image identity only when an operator explicitly enables the OCI plugin.

```text
HACO_PLUGIN_OCI=nerdctl  # or docker
haco plugin oci seed sample
haco plugin oci seed recommend
```

The trusted Host stores the latest snapshot per Environment: sample time, repository, tag when present, and immutable digest when available. It does not record shell history, container output, registry secrets or Workspace content.

Recommendations count distinct recent Environments rather than repeated samples. Mutable-tag-only observations are never eligible for Seed identity. The current selection policy marks the top 10% of eligible recommendations for automatic inclusion by a future Seed Builder; it does not mutate a Base or Seed today.

OCI tooling remains optional. With `HACO_PLUGIN_OCI` unset, this service is not composed and Hacocoon Core does not require nerdctl or Docker.
