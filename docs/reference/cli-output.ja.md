# CLI 出力ポリシー

製品版 `haco` は、人間が読みやすい出力をデフォルトのインターフェースとします。

- 通常のコマンドは、人向けの短いメッセージ、表、key/value 形式などで表示します。
- 機械可読な JSON は、ユーザーが明示的に `--json` を指定した場合だけ出力します。
- 正常なコマンド結果は stdout に出力します。
- エラー、診断、進捗、警告、対話プロンプトは stderr に出力します。
- 一覧表など、すでに専用の人向け表示を持つコマンドは、その表示を優先します。

スクリプトから結果を利用する場合は必ず `--json` を指定し、デフォルトの人向け表示形式には依存しないでください。

公開CLIではない内部連携用エントリポイントは、必要に応じて固定の機械可読形式を使用できます。特に `_reclaim-linux` は Windows/Linux 間の内部ハンドオフ用プロトコルのため JSON 固定を維持します。公開コマンド `haco reclaim` は通常の人向け出力ルールに従います。
