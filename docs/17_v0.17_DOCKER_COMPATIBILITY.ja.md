# v0.17 — Docker Compatibility

[English](17_v0.17_DOCKER_COMPATIBILITY.md) | **日本語**

Status: **optional pluginのpackaging foundationは実装済み。Base/Seed integrationとreal-host lifecycle acceptanceはpending。**

Dockerはcompatibility interfaceであり、Hacocoon Core runtimeではない。

project-maintained OCI pluginでは`containerd + nerdctl` profileを選べる。genuine Docker semanticsを要求するdeveloper tooling向けには、optional Docker profileで本物のDocker CLIとEnvironment-local Docker Engine互換経路を提供できる。

```text
Docker CLI / API client
        |
/run/docker.sock
        |
plugin-owned systemd socket activation
        |
      dockerd
        |
existing Environment containerd
```

## Rule

- `HACO_PLUGIN_OCI`未設定でもCoreは成立し、Environment管理だけのためにDocker/nerdctl/containerdを要求しない
- Docker CLIはHacocoon wrapperではなくgenuine Docker CLI
- `dockerd`をmandatory always-on Hacocoon daemonにしない
- Host Docker socketをEnvironmentへmountしない
- Docker APIはdefaultでEnvironment-local
- Docker socketへaccessできるuserはそのEnvironment内でroot-equivalentとして扱う
- OCI content sharingとtotal storageの完全dedupは同義ではない
