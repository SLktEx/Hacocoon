# v0.18 — Optional Local OCI Registry

Status: **planned; not implemented as required Hacocoon infrastructure.**

Normal Environment pulls remain normal upstream OCI pulls unless an operator explicitly enables a registry/proxy integration.

```text
Default:
Environment -> allowed upstream registry

Optional:
Environment -> operator-selected local registry/proxy -> upstream
```

A Local Registry may be useful for repeated download cost, rate limits, restricted Internet environments, or a centralized OCI policy/audit point. It is **not** required for OCI Seed construction and must not become a Core dependency.

Authentication is a separate authority problem. Host registry credentials are not silently copied into coding Environments. A future scoped credential-broker plugin may be used without forcing image data through a local proxy.

If mediation is configured as mandatory, registry failure must not silently fall back to unrestricted direct Internet access.
